# Learn to Code 1

> **English:** Command Byte: commands, functions, loops, conditionals—computational thinking.

**一句講完：** 指揮 Byte：指令、函式、迴圈、條件——計算思維入門。

| **類型** | Playground Book（`.playgroundbook`） |
| **圖庫位置** | Apple Swift Playground 圖庫／Get Started（Feed `7A53`） |

## 點樣打開

1. 安裝 [Swift Playground](https://apps.apple.com/app/swift-playground/id1496833156)（Mac／iPad）。
2. Swift Playground → Get Started／Learn → Learn to Code 1。
3. 第一次下載可能要等；完成後跟書內 **intro／提示** 開始。

用已下載嘅 zip（自行由 Apple CDN 攞，**唔好** commit 入 git）：

```bash
# 例：下載後解壓再開
open -a "Swift Playground" "/path/to/extracted-book-or-swiftpm"
```

## 學習目標／課堂建議

- 掌握 moveForward / turnLeft / collectGem / toggleSwitch（以書內 API 為準）
- 建立「最短清楚路線」同 Debug 習慣
- 90 分鐘堂：概念 15 → 上機 40 → 休 10 → 挑戰 12 → 收結
- 詳見本 repo 根目錄指南

---

## 關鍵概念／API

`moveForward()`、`turnLeft()`、`collectGem()`、`toggleSwitch()`；之後函式、`for`、`if`／`while`。

若書內 API 同本頁描述有出入，**一律以 App 內說明為準**。
