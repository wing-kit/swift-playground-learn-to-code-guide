# Rock, Paper, Scissors

> **English:** Encode rock-paper-scissors rules: randomness, win/lose, scoring.

**一句講完：** 用程式表達剪刀石頭布規則：隨機、比較勝負、計分。

| | |
|--|--|
| **適合邊啲人** | 初學（遊戲邏輯）／ Intermediate game logic |
| **類型** | Playground Book（`.playgroundbook`） |
| **圖庫位置** | Apple Swift Playground 圖庫／Get Started（Feed `7A53`） |

---

## 點樣打開

1. 安裝 [Swift Playground](https://apps.apple.com/app/swift-playground/id1496833156)（Mac／iPad）。
2. Swift Playground → Get／圖庫 → Rock, Paper, Scissors（或自行下載 CDN zip 後雙擊打開）。
3. 第一次下載可能要等；完成後跟書內 **intro／提示** 開始。

用已下載嘅 zip（自行由 Apple CDN 攞，**唔好** commit 入 git）：

```bash
# 例：下載後解壓再開
open -a "Swift Playground" "/path/to/extracted-book-or-swiftpm"
```

## 學習目標／課堂建議

- 理解「玩家選擇 → 電腦選擇 → 比較 → 結果」流程
- 練習條件判斷（邊個贏）
- 課堂：兩人一組，先口頭講規則再上機對照
- 延伸：加「三局兩勝」或顯示連勝
- 提醒：本 repo 只有教程，遊戲邏輯請跟書內 intro
