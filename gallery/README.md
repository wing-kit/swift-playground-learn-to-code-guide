# Swift Playground 圖庫教程總目

> **English:** Original classroom-oriented notes for every item in the Apple Swift Playground gallery (feed `7A53`). Links to official CDN zips only—**no binaries in this repo**.

本目錄為 **38／38** 個圖庫項目各寫一頁原創教程（繁中為主）。

- 根目錄 Learn to Code 焦點指南：[../README.md](../README.md) · [English](../en/README.md)
- CDN URL 總表：[../docs/CDN-MANIFEST.md](../docs/CDN-MANIFEST.md)

## 點樣用

1. 喺 Swift Playground App 圖庫下載對應項目，或用各頁 CDN 連結自行下載。
2. 打開後跟 **App 內 intro**；本站只提供教學目標同課堂建議。
3. **唔好** 把 Apple zip／playgroundbook commit 入任何公開 git。

## 建議學習路徑（課堂）

1. **程式基礎：** Get Started with Code → Learn to Code 1 → Learn to Code 2 → Puzzle World
2. **故事／趣味：** Blu's Adventure → Answers → Rock, Paper, Scissors → Battleship
3. **聲音／感測：** Sonic Workshop → Sound Pad → Sensor Arcade → Seismometer → Create 系列
4. **相機／AR：** Lights, Camera, Code → Assemble Your Camera → Flashy Photos → Capturing Photos → AR
5. **App／SwiftUI：** Get Started with Apps → About Me → Choose Your Own Story → Keep Going with Apps → Layout／Grids／Gestures
