# Byte primitives cheatsheet（原創速查）

| Call | 作用 |
|------|------|
| `moveForward()` | 向前一格 |
| `turnLeft()` | 左轉 90° |
| `turnRight()` | 右轉 90° |
| `collectGem()` | 執當前格寶石 |
| `toggleSwitch()` | 切換當前格開關 |

```swift
// 原創示意：行 → 轉 → 執
moveForward()
turnLeft()
moveForward()
collectGem()
```

Run：**Run My Code** 或 ⌘R。
