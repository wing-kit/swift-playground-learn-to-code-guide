## How to download yourself

```bash
mkdir -p ~/Playgrounds/cdn && cd ~/Playgrounds/cdn
# Example — Learn to Code 1
curl -fL -O "https://playgrounds-cdn.apple.com/7A53/Content/LearntoCode1/LearntoCode1.playgroundbook.zip"
unzip LearntoCode1.playgroundbook.zip
open -a "Swift Playground" ./LearntoCode1.playgroundbook
```
